# NoritsubushiCN

把坐过的线路，一段一段收藏起来。

一个记录中国轨道交通「完乘」的浏览器工具。每次坐完一段线路，记下起点、终点和日期；哪些区间已经坐过、还差多少，由它来算。不注册、不上传，记录只留在你自己的设备上。

本仓库是它的公开前端：Web 应用、共享模块，以及一份完全虚构的演示数据。

> 名字来自日语「乗りつぶし」（noritsubushi），意思就是「坐遍」。

## 什么是「完乘」

「完乘」指的是把一张线网上的每一段都坐到。铁路爱好者把它当集章——一条线从起点坐到终点，把沿途区间收进自己的记录；通勤的人也可以把它当成一张只属于自己的城市地图：每天经过的那几站，同样算数。

NoritsubushiCN 把这个过程做成一本能自动计算的记录本：**你只管记下坐过的区间，还有哪些没坐、完成了多少，由它来算。**

## 现在能做什么

- **记一次乘车**：按线路或按车站找到那一段，选起终点和日期，保存。已经记过的区间不会重复保存，系统只补上还没坐的部分。
- **看完成度**：按城市、运营商、线路，看已经坐了多少里程或多少区间、车站完成了几座；可以切到过去某一天，看当天为止的进度。
- **备份与恢复**：把记录导出成一个文件，换设备或清理浏览器前先备份。导入会整体替换当前设备上的记录，不会悄悄合并。
- **进阶记录**：同一趟车从一条线直通到另一条线时，按顺序记录完整径路；中途换乘则另记一条。车站进度只由进阶记录的起点和终点计算。
- **线路示意图**：把线网画成自绘的示意图，标出车站与区间、运营区间和临时停运区间，不使用在线地图，也不需要加载底图。

## 你的记录只属于你

- 没有账号，不需要注册，也没有保存你记录的服务器。
- 记录存在浏览器的本地数据库里。页面不会把你的记录发给任何人，也没有统计或广告脚本。
- 反过来，换浏览器、换设备、清理浏览器数据，记录就没了。请定期用「备份」导出文件。

## 为什么现在还不能直接用

目前还没有对公众开放，也没有公开试用入口。

原因主要在数据。内部测试使用的是广州、佛山的真实线网数据，这些数据来自公开地图等来源，公开使用还卡在许可与署名条件上，目前只能用于内部验证，不能随仓库或网站提供。公开仓库里带的是另一份完全虚构的演示数据——一座示例城、两条线路、13 座车站——任何人都可以用它把项目跑起来。

当前状态大致是：

- 基础记录、统计、备份已经能完整走通，还在做发布前的体验与合规检查；
- 进阶链式记录与车辆信息已经实现主要流程，仍在打磨细节；
- 地图图片导出暂缓，等线路走向数据可用后再做；
- 账号与跨设备同步不在当前阶段。

所以目前想见到它，最直接的方式是在电脑上按下面的步骤跑起来，看到的是示例城；公开试用开放后，入口会在这里公布。

如果你在界面上看到顶部的「内部测试」和「尚不具备正式发布条件」，那是刻意保留的状态说明，不是报错。

## 在电脑上跑起来

需要 Node.js 24（`>=24.15.0 <25`）与 npm（`>=10.8.2 <12`）。在终端里：

```bash
git clone https://github.com/JefferyYoung-CN/NoritsubushiChina.git
cd NoritsubushiChina
npm ci --ignore-scripts
npm run dev
```

然后打开 <http://127.0.0.1:5173>。这里看到的是虚构的示例城，不会连接真实数据，也不会把你的记录传到任何服务器。

如果只是想把项目跑起来看看，到这里就够了。想改代码、跑检查或部署，再展开下面这一段。

### 常用命令

在仓库根目录运行：

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 发布演示数据并启动开发服务器（`127.0.0.1:5173`） |
| `npm run typecheck` | 类型检查 |
| `npm test` | 应用测试 + Web 测试 |
| `npm run build` | 类型检查后构建生产包 |
| `npm run preview` | 预览已有的构建产物（`127.0.0.1:4173`，需先 `build`） |
| `npm run verify:gates` | 反向探针：确认类型检查与测试发现确实会失败 |
| `npm run demo:generate` | 重新生成 `demo/` 中的合成演示数据 |
| `npm run prepare:assets` | 从数据根发布浏览器用的数据信封 |

所有命令都应以退出码 0 结束。

### 目录

```text
.
├─ apps/web/               # Vue 3 Web 应用
├─ packages/application/   # 读取、记录、统计、存储等共享模块
├─ tools/                  # 资源发布、测试运行器、门禁探针
├─ demo/                   # 合成演示数据集
└─ LICENSE                 # AGPL-3.0
```

### 技术栈与说明

Vue 3 + TypeScript + Vite；记录存 IndexedDB；数据以带摘要校验的 JSON 信封提供。Web Crypto 需要安全上下文，`127.0.0.1` 和 `localhost` 满足要求，远程部署必须使用 HTTPS。

数据根等细节见 [`apps/web/README.md`](apps/web/README.md)，演示数据结构见 [`demo/README.md`](demo/README.md)。
